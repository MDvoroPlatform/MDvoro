# MDvoro Phase 32 — Board Success Center

This phase turns the product from a feature collection into a board-exam preparation workflow.

## New learner experience
- Board Success Center on the dashboard.
- Daily target progress using real server-recorded question activity.
- Due-card count, streak, days remaining, and adaptive next actions.
- Exam blueprint coverage by branch.
- Mistake profile: total wrong, high-confidence wrong, low-confidence wrong, slow wrong.
- Fourteen-day activity consistency view.
- One-tap full-exam simulation entry using the configured official exam item cap.
- Exam Guide page with Israel-first IMLE structure, core subjects, and official reference-book pointers.
- Mobile navigation entry for Exam Guide.
- QBank Quick Start now includes full simulation.

## Design principle
The product should help the learner answer four questions immediately:
1. What should I do now?
2. What am I weak at?
3. How much of my target exam have I actually covered?
4. Am I training under realistic exam conditions?

The system intentionally does not claim that an internal readiness index guarantees a pass or predicts an official score.
